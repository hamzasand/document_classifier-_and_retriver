# Document AI System

## Features

- PDF/Text document ingestion
- Document classification
- Structured information extraction
- Semantic document retrieval

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

## Libraries Used

- PyMuPDF
- SentenceTransformers
- FAISS
- NumPy

## Output

Results are saved in:

output/output.json
